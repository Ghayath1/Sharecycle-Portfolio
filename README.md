# ShareCycle 🚲

A full-stack bike rental platform built with Flutter, Spring Boot, and React.

 Architecture

- Frontend: Flutter Mobile Application
- Backend: Spring Boot REST API
- Dashboard: React Admin Dashboard
 Features

- User Authentication (JWT)
- Bike Management
- Bike Booking System
- Order Management
- Admin Dashboard
- Google Maps Integration
- PayPal Payment Integration
- User Profile Management
- Image Uploads

Technologies

 Frontend
- Flutter
- Dart
- Provider
- GoRouter
- Google Maps

Backend
- Spring Boot
- Java 17
- Spring Security
- JWT
- Spring Data JPA
- PostgreSQL
- Maven

 Dashboard
- React
- JavaScript
- REST API Integration
